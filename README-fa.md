# GHOSTI RADIO — نسخه اول

این نسخه یک Prototype کاملاً مینیمال است:
- لوگوی Ghosti داخل سایت قرار گرفته.
- موزیک‌ها داخل خود صفحه با HTML5 Audio پخش می‌شوند.
- با دکمه `manage` می‌توانی فایل‌های صوتی را اضافه کنی.
- آهنگ‌ها در IndexedDB همین مرورگر ذخیره می‌شوند و با Refresh باقی می‌مانند.
- برای حذف آهنگ‌ها، `manage` را روشن کن و روی × بزن.

## اجرا
ساده‌ترین روش:
1. کل پوشه را روی کامپیوتر نگه دار.
2. فایل `index.html` را با Chrome یا Edge باز کن.
3. روی `manage` بزن.
4. موزیک‌های MP3 را انتخاب کن.
5. روی Play بزن.

## نکته مهم
این نسخه برای تست و طراحی اولیه است و هنوز «سایت عمومی با پنل مدیریت آنلاین» نیست.
اگر این پوشه را روی اینترنت منتشر کنی، آهنگ‌هایی که در بخش Manage اضافه می‌کنی فقط در مرورگر خودت ذخیره می‌شوند؛ بازدیدکننده‌های دیگر آن‌ها را نمی‌بینند.

مرحله بعدی برای نسخه واقعی:
- هاست + دامنه
- فضای ذخیره‌سازی آنلاین برای MP3
- دیتابیس آنلاین
- پنل Admin با رمز
- Playlist مشترک برای همه بازدیدکننده‌ها

وقتی نسخه اولیه را پسندیدی، همین ظاهر را بدون تغییر می‌توانیم به نسخه آنلاین تبدیل کنیم.
